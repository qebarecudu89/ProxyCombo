# Proxy Combo

Менеджер прокси + чистильщик Chrome + ротация IP в одном окне.

## Установка
`pip install -r requirements.txt`
`python main.py`

## Запуск
| Команда | Что делает |
|---------|------------|
| `python main.py` | Обычный запуск |
| `python main.py --debug` | Подробная отладка |
| `python main.py --build` | Собрать `ProxyCombo.exe` |
